# RentZilla Google Play Assets

This directory contains the validated store-listing assets for the RentZilla Android app.

## Upload files

### App icon

- `play-store-icon-512.png`
- Size: 512 × 512 pixels
- Format: PNG

### Feature graphic

- `feature-graphic-1024x500.png`
- Size: 1024 × 500 pixels
- Format: PNG
- Contains no ratings, testimonials, review scores, red markup, prices, or unsupported claims

### Phone screenshots

All screenshots are 1080 × 1920 portrait PNG files captured from the running RentZilla app interface.

Recommended Play Console order:

1. `screenshots/02-customer-home.png`
2. `screenshots/03-customer-search.png`
3. `screenshots/04-customer-bookings.png`
4. `screenshots/05-provider-dashboard.png`
5. `screenshots/06-provider-bookings.png`
6. `screenshots/01-sign-in.png`

## Suggested screenshot alt text

1. **Customer home:** RentZilla customer home showing search, equipment and service categories, and available rentals.
2. **Customer search:** RentZilla search screen showing category filters, popular searches, and Punjab location browsing.
3. **Customer bookings:** Customer booking history showing rental names, dates, and booking status.
4. **Provider dashboard:** Provider dashboard showing earnings, listings, booking requests, and management actions.
5. **Provider bookings:** Provider booking-management screen showing the current booking state.
6. **Sign in:** RentZilla sign-in screen with email login and links to sign up, Privacy Policy, and Terms.

## Validation

`asset-manifest.json` records the verified dimensions, file formats, file sizes, and SHA-256 checksums for every upload asset. Its top-level `validated` value must remain `true`.

The screenshots represent the real app UI. Do not add device frames, fabricated reviews, unsupported ratings, or functionality that is not available in the app.
