# 🚀 RentZilla – Full App Build Prompt (Optimized for Replit AI Agent)

## 🎯 Objective

Build a **production-ready mobile-first rental marketplace app** for Punjab, India where users can:

* Rent cars
* Rent agricultural equipment (tractors, harvesters, rotavators)
* Book local services (plumbers, electricians, beauty services)

The app must be **fast, simple, scalable, and usable by both rural and urban users**.

---

## 🧱 Tech Stack (STRICT)

* Frontend: **Flutter (Android + iOS)**
* Backend: **Firebase (Auth + Firestore + Storage + Functions)**
* API: REST-style structure using Firebase services
* Authentication: **Phone OTP (Firebase Auth)**

---

## 🌍 Region & Localization

* Region lock: **Punjab, India only**
* Currency: **₹ INR**
* Languages:

  * English (default)
  * Punjabi (Gurmukhi)
* Implement language toggle with JSON-based translations

---

## 👥 User Roles & Permissions

### 🧑 Customer

* Phone OTP login
* Browse categories:

  * Cars
  * Agricultural Equipment
  * Services
* Search + filters (price, rating, distance)
* View listing details
* Book item/service (date & time selection)
* Make payments (UPI + optional COD)
* View booking history
* Submit ratings & reviews

---

### 🧑‍🔧 Provider (Vendor)

* Register/login via phone
* Create/edit profile
* Add listings:

  * Title, description, category
  * Price (per day/hour)
  * Images (Firebase Storage)
  * Availability calendar
  * Location
* Accept/reject bookings
* Manage bookings dashboard
* View earnings summary
* Chat with customers

---
