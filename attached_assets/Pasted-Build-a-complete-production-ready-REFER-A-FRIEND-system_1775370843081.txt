Create a referral system visible in SETTINGS TAB for both:
1. Customer app
2. Provider app

Referral rewards unlock ONLY after 5 successful completions.

---------------------------------------------------
CUSTOMER REFERRAL LOGIC
---------------------------------------------------

RULE:
- customer must refer at least 5 friends
- each referred friend must:
   1) sign up
   2) use referral code
   3) complete first booking successfully
- only after all 5 complete first booking:
   referrer gets 10% OFF on next booking

IMPORTANT:
- reward applies only once after each batch of 5
- after reward is used, next cycle starts again
- partial progress should be tracked
- invalid or cancelled bookings do not count

Example:
Friend completions = 5
→ unlock promo reward = 10% OFF next booking
→ add reward to promo vault

---------------------------------------------------
PROVIDER REFERRAL LOGIC
---------------------------------------------------

RULE:
- provider must refer at least 5 provider friends
- each referred provider must:
   1) sign up
   2) use referral code
   3) complete first JOB successfully
- after 5 successful first jobs:
   referrer provider gets EXTRA 10% earnings bonus on NEXT completed booking/job

IMPORTANT:
- applies only on provider’s next completed booking
- bonus calculated on provider payout share
- after bonus use, cycle resets
- cancelled jobs do not count

Example:
Provider payout = ₹1,000
Referral bonus = +₹100
Provider receives = ₹1,100
