Build a full Admin Pricing & Commission Control module in the Rentzilla admin app with category-wise formulas, dropdown controls, and dynamic pricing management for all services, professions, and equipment.

---

# 🎯 MAIN GOAL

Admin should be able to control:

* Customer pricing
* Provider payout
* App commission
* Platform fees
* Urgent charges
* Distance charges
* Hourly pricing
* Equipment daily/hourly pricing

Everything must be editable from Admin App without changing code.

---

# 📱 ADMIN APP LOCATION

Add this module inside the **left 3-line menu (drawer menu)** in admin app.

Menu item:

### 💰 Pricing & Commission Control

# 💰 DIFFERENT PRICING FORMULAS BY CATEGORY

## 🛠 SERVICES / PROFESSIONS FORMULA

```text
Customer Price = Base Visit Fee + Labor Charge + Material Fee + Distance Fee + Urgency Fee + Platform Fee
```

### Admin controls:

* Base visit fee
* Labor charge
* Hourly rate
* Distance per km
* Urgency fee
* Platform fee
* Commission %

---

## 🏗 EQUIPMENT FORMULA

```text
Customer Price = Rental Rate (hour/day) + Delivery Fee + Fuel Fee + Operator Fee + Platform Fee
```

### Admin controls:

* Hourly rate
* Daily rate
* Delivery charge
* Fuel charge
* Operator fee
* Security deposit
* Commission %

# 🔌 APIs REQUIRED

## GET /admin/pricing-rules

Return all pricing rules

---

## POST /admin/pricing-rules

Create or update rules

---

## GET /pricing/calculate

### Input:

* category
* subcategory
* duration
* distance
* urgency

### Output:

* customer_price
* provider_payout
* app_commission
