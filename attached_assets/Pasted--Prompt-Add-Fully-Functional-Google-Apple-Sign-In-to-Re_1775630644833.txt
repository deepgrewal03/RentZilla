4) Required Backend APIs
A) Google Auth API
POST /api/auth/google

Payload:

{
  "id_token": "",
  "device_type": "android/ios/web",
  "app_version": ""
}
B) Apple Auth API
POST /api/auth/apple

Payload:

{
  "identity_token": "",
  "apple_user_id": "",
  "device_type": "ios"
}
C) Response Format
{
  "success": true,
  "user": {
    "id": "",
    "name": "",
    "email": "",
    "photo_url": "",
    "provider": "google/apple"
  },
  "access_token": "",
  "refresh_token": "",
  "is_new_user": false
}
