When user taps Contact Support:

Open email composer automatically
Default recipient:
info.rentzilla@gmail.com

RentZilla Support Request

User name
Registered mobile/email

Device type
Message placeholder

Open an in-app support form modal

Name
Email / Mobile
Issue Category
Message

Send support request to:
info.rentzilla@gmail.com

Booking issue
Payment refund
Provider verification
Listing problem
Technical bug
Safety report
Other

{
