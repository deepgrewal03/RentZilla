Build a production-ready marketplace payment architecture for the RentZilla app.

STACK:
- React Native Expo frontend
- Node.js + Express backend
- MongoDB / Firestore
- Stripe Connect marketplace payments
- Provider wallet system
- Customer wallet system
- Admin commission system
- Delayed payout support

GOAL:
Create a complete payment flow where:
1. Customer pays using:
   - saved card
   - UPI
   - Apple Pay / Google Pay
   - in-app wallet (default priority)
2. Payment first goes to RentZilla platform master account
3. Platform deducts commission automatically
4. Remaining amount moves to provider wallet
5. Provider can choose:
   - instant transfer to bank
   - weekly automatic payout
   - keep in wallet
6. Weekly payouts auto-transfer every Monday
7. Support refunds and disputes
8. Must work in production after Expo publish

------------------------------------------------
CUSTOMER PAYMENT FLOW
------------------------------------------------

PAYMENT PRIORITY:
- First use in-app wallet balance
- If insufficient:
   use saved payment method automatically
- fallback:
   open payment sheet

FLOW:
Customer books vehicle/equipment
→ amount blocked immediately
→ payment success webhook
→ amount settles in RentZilla account
→ booking status = paid
→ trip/order activated

Example:
Rental amount = ₹10,000
Security hold = ₹2,000
Platform commission = 15%

Split:
- RentZilla = ₹1,500
- Provider = ₹8,500
- Deposit = held separately till completion

------------------------------------------------
PROVIDER PAYOUT FLOW
------------------------------------------------

After trip completion:
1. deduct late fees / penalties if any
2. release security deposit
3. move provider share to provider wallet
4. provider sees:
   - available wallet balance
   - pending weekly payout
   - instant bank transfer button

PAYOUT OPTIONS:
A) Instant bank transfer
- transfer immediately to saved bank account
- optional instant payout fee 1%

B) Weekly payout
- auto transfer every Monday 9 AM
- batch all completed earnings
- mark payout as processing
- payout history visible

C) Keep in wallet
- use for app ads, subscriptions, boosts

Stripe supports manual, weekly, and instant payout schedules. :contentReference[oaicite:2]{index=2}

------------------------------------------------
BACKEND APIs
------------------------------------------------

POST /api/payments/create-intent
- create booking payment intent
- use wallet first
- charge remaining from card

POST /api/payments/confirm
- confirm payment success
- save transaction

POST /api/providers/payout/instant
- transfer wallet amount to bank immediately

POST /api/providers/payout/schedule
- set payout preference:
   instant | weekly | wallet

GET /api/providers/wallet
- fetch wallet balance
- pending payouts
- completed payouts

POST /api/payments/refund
- refund customer
- reverse provider pending payout if not released

------------------------------------------------
AUTOMATION JOBS
------------------------------------------------

Create cron jobs:

1) weeklyPayoutJob

2) expiredDepositReleaseJob
- release security hold after return approval

3) failedPayoutRetryJob
- retry failed bank payouts
