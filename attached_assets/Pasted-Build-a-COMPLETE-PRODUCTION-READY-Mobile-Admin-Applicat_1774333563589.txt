Build a COMPLETE, PRODUCTION-READY Mobile Admin Application for RentZilla (rental + ride-booking platform).

IMPORTANT:
- This must be a separate mobile app (independent frontend)
- It must connect to the existing RentZilla backend via secure APIs
- Do NOT create a new database
- Sync all data in real-time with main app
- Must support scalability (future growth)

-----------------------------------

🎯 MAIN GOAL:

Create a powerful admin mobile app to:
- Monitor platform activity
- Control users, providers, rides, listings
- Manage payments, safety, and growth

-----------------------------------

📱 TECH STACK:

Frontend:
- React Native (Expo)
- NativeWind (Tailwind for mobile)

Backend:
- Use existing APIs (Node.js / FastAPI)

Realtime:
- WebSockets or Supabase Realtime

Authentication:
- JWT + Role-based access (admin only)

-----------------------------------

🔐 AUTH SYSTEM:

- Admin login (email/password)
- Only role = admin can access
- Add optional 2FA (OTP)
- Auto logout on token expiry

-----------------------------------
