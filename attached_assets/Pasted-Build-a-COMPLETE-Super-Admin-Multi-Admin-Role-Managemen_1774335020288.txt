🎯 MAIN GOAL:

-----------------------------------

👨‍💼 ADMIN ROLES SYSTEM

-----------------------------------

1. ROLE TYPES:

- super_admin:
  → full access
  → manage admins
  → full system control

- admin:
  → manage users, providers, rides, payments
  → cannot manage other admins

- moderator:
  → handle reports, block users, view data

-----------------------------------

2. PERMISSIONS MATRIX:

Create granular permissions:

- manage_users
- manage_providers
- manage_rides
- manage_payments
- manage_documents
- manage_reports
- send_notifications
- manage_admins (super_admin only)

-----------------------------------

3. DATABASE STRUCTURE:

Admins Table:
- id
- name
- email
- role (super_admin, admin, moderator)
- permissions (JSON)
- created_at

AdminLogs:
- id
- admin_id
- action
- target_type (user, ride, etc.)
- target_id
- timestamp

-----------------------------------

4. ADMIN MANAGEMENT (SUPER ADMIN ONLY):

- Create admin
- Assign role
- Edit permissions
- Disable admin
- View admin activity logs

5. SECURITY:
